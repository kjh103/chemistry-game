# 🧪 옥텟 규칙을 만족하라! - 원소 결합 퍼즐 게임

## 게임 소개
원소의 화학 결합을 재미있게 배울 수 있는 인터랙티브 웹 게임입니다.

**옥텟 규칙(Octet Rule)**: 원자는 최외각 전자가 8개일 때 가장 안정적인 상태가 됩니다.

## 게임 방법

1. **하단의 원소 카드(H, O, Na, Cl)를 결합 공간으로 드래그**
2. **"결합 완료 및 판정" 버튼 클릭**
3. **정확한 화합물이 만들어지면 성공!**

## 학습 가능한 화합물

### 1️⃣ 염화나트륨(NaCl) - 이온 결합
- **필요한 원소**: Na 1개 + Cl 1개
- **설명**: 나트륨의 최외각 전자 1개가 염소로 완전히 이동
- **쓰임새**: 우리가 매일 먹는 소금의 주성분

### 2️⃣ 물(H₂O) - 공유 결합
- **필요한 원소**: H 2개 + O 1개
- **설명**: 산소가 수소의 전자와 쌍으로 공유
- **쓰임새**: 모든 생명체에 필수적인 물질

## 기술 스택

- **HTML5**: 의미론적 구조
- **CSS3**: Flexbox, Animations, CSS Variables
- **JavaScript (Vanilla)**: Drag & Drop API, DOM 조작

## 플레이 방법

1. `index.html`을 웹 브라우저에서 열기
2. 원소 카드를 끌어다 놓기
3. "결합 완료 및 판정" 클릭
4. 성공 메시지 확인
